Medical Appointment System

AI Prescription Suggestions

An AI safety layer that analyses prescribed medicines against a patient's full history — detecting drug-allergy conflicts and recommending follow-up procedures in real time.

The Challenge

Digital prescriptions lacked cross-referencing with full patient history, creating risk of drug-allergy conflicts and missed procedural follow-ups.

The Solution

Integrated an LLM API with custom prompt engineering to analyze prescribed medicines against stored patient history and medical reports in real time.

The Impact

A "Safety-First" layer that flags allergies and suggests standard follow-up procedures — like mandatory blood tests for specific medications — before finalizing.

@if (showCode()) { 
@Service
@RequiredArgsConstructor
public class PrescriptionSafetyService {

  @Value("${llm.api.key}")
  private String llmApiKey;

  public SafetyAnalysisResult analyze(
      Prescription rx, PatientHistory history) {

    // Build context-aware prompt — no raw PII in log output
    String prompt = """
        Patient allergies  : %s
        Active conditions  : %s
        Prescribed today   : %s

        Flag drug-allergy conflicts, contraindications,
        and list mandatory follow-up procedures as JSON.
        """.formatted(
          history.getAllergies(),
          history.getConditions(),
          rx.getMedicationsSummary()
        );

    LLMResponse raw = llmClient.complete(
      SystemMessage.of(CLINICAL_SAFETY_SYSTEM_PROMPT),
      UserMessage.of(prompt)
    );

    // Deserialize into typed SafetyAnalysisResult (alerts + procedures)
    return objectMapper.readValue(
      raw.content(), SafetyAnalysisResult.class
    );
  }
}
